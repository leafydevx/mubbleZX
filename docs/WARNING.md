1. Introduction
MubbleZX is a multi‑version network diagnostics tool designed for authorized environments such as home networks, labs, and enterprise networks where the operator has explicit permission to perform scanning.

The tool provides:

Host discovery

Port scanning

OS fingerprinting

Device classification

JSON‑structured reporting

Versioned improvements across releases

MubbleZX is strictly a defensive, diagnostic, and compliance‑aligned tool.
