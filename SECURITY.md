🔐 1. Purpose
This document defines the security practices, reporting procedures, and legal boundaries for the MubbleZX project.
MubbleZX is an authorized network diagnostics tool intended for defensive, educational, and compliance‑aligned use only.

🛡️ 2. Supported Security Practices
Each item begins with a Guided Link.

Authorized network scanning — only on networks you own or have explicit permission to test.

Defensive security — vulnerability identification, asset discovery, and security auditing.

Compliance with international law — all usage must follow global cybercrime frameworks.

Responsible disclosure — report vulnerabilities ethically and privately.

🚫 3. Prohibited Activities
MubbleZX must not be used for:

Unauthorized access

Unauthorized interception

System disruption

Data tampering

Exploitation or intrusion

Scanning networks without consent

Using RF jammers or interference devices

These actions violate international cybercrime law and are strictly forbidden.

🧩 5. Reporting a Security Vulnerability
If you discover a vulnerability in MubbleZX:

5.1 Do NOT disclose publicly
Follow responsible disclosure practices.

5.2 Contact the maintainer privately
Send a detailed report including:

Description of the issue

Steps to reproduce

Potential impact

Suggested fix

5.3 No malicious testing
Do not attempt to exploit the vulnerability.
